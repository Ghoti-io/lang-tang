# Divergence ledger

Every way lang-tang is allowed to differ from frozen ctang is a row below.
Nothing else is. ctang is the oracle (spine AD-16): every corpus file is parsed
by both and then run by both, and a difference that no row names fails the
differential. What a run is compared on is the rendered output bytes and the
final result, the result being its kind and a canonical text
(an error is its kind and message, never where it came from; a container is its
count, an array also its elements one level down); a program lang-tang pauses
on its budget and the harness kills ctang on agrees, and nothing else does.
ctang retires when the ledger is **closed**, meaning no row is `open` (AD-3).

| Column | Meaning |
| --- | --- |
| `id` | `D-001`, `D-002`, ... Never reused. |
| `category` | `ctang-defect` (ctang is wrong and lang-tang is right), `limit` (a bound ctang has no equivalent of), `error-reporting` (how an error reaches the host), `rng` (the random generator). |
| `status` | `open` (nobody has decided yet), `recorded` (a deliberate departure, accepted), `fixed` (the difference is gone). Only a `recorded` row that names corpus files accepts a divergence on them, and it is **stale**, and fails the differential, once the named file stops diverging. |
| `ref` | The number of the language reference's section 13 item the row comes from, or `-`. |
| `corpus` | The corpus files (under `tests/corpus/`, comma separated) the row covers, or `-`. |
| `resolved-by` | The story that decides the row or records its end state. |
| `summary` | What differs and why. |

The table is validated by `tests/unit/test_ledger.cpp`: unique ids, valid
categories and statuses, every named corpus file exists and is named by one row
only, and a malformed row fails (shown on a planted ledger).
`tests/oracle/test_oracle.cpp` holds the differential against it. A row that
covers a divergence in output or result names the files that show it, so that
it goes stale the day they agree; a row with no file says in its summary why it
has none (a budget, an outcome only a host sees, an error list).

| D-003 | rng | recorded | - | - | 10 | ctang shares one `random.global` across the whole process and seeds `random.default` from the clock. lang-tang gives each execution its own `random.global`, made on first access with a seed from the execution's seed sequence, and every read of `random.default` is a new generator seeded from the same sequence.
